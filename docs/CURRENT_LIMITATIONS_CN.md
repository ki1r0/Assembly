# 当前结果与限制（2026-10-28）

- 直立 peg 曾完成插入、释放、撤退，CAPE 开发过程判据得到物理正例。最新独立重跑未重现，角速度保护停止；不能把历史正例当成最新回合 native success。
- 平躺 peg 尚无当前 xArm 全过程完成证据；抓法、姿态可达性、恢复和接触仍有问题。
- Hub 曾局部稳定抬升约 57.6 mm，但当前完整自主回合未完成装配，抓取仍不稳。
- CAPE 正式物理校准尚未结束；`assembly_success` 可能为 null。在线 native_success 是开发物理完成信号，见 benchmark 文档。
- 模拟 RGB-D 是固定理想相机，不是已校准的特定 RealSense 噪声模型；FT 是模拟反力，不是实机传感器驱动。
- xArm/G1 为仿真假设；真实夹爪与额定负载应按硬件确认。代码不包含已验收的真机后端。
- 机械臂/桌面候选筛选只检查离散配置，不保证整段路径无碰撞；保留原生速度、关节、力与跟踪保护。
- 1x/2x 无载参考速度对照都通过，但 wall time 只改善约 8%，未将 2x 推广为正式带载默认。
- 安装仍需要外部 gearbox CAD 资产集合及 NVIDIA 机器人资产，不能仅 clone 即跳过资产准备。当前 CAD 缓存准备保留原任务集合依赖。
